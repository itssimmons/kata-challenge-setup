# Lua Kata Challenge Setup

This repository contains a simple setup for coding kata challenges in Lua. It includes a main file for the challenge implementation and a test file to verify the solution.

## How to run

```lua
luarocks install kata-1.0.0-1.rockspec
./lua main.lua
```

## How to test

```lua
luarocks install kata-1.0.0-1.rockspec
./lua test_main.lua
```
